# 2027 指挥屏适配

依据本地《RoboMaster 2027 University Series Communication Protocol V1.0.0》
（2026-11-02）第 2.2.4、2.2.6、2.2.13、2.2.19 节和附录 II。

本次限定指挥屏，保留主操作画面布局与工业相机的其他使用入口。
Ctrl+Y 原布局切换保留：地图主视图 / 领地控制主视图；两种布局均不再显示工业相机。

- 指挥机器人阵容为 1（重型工程）、3、4、6、7，不含 2。
- 雷达数组依次为敌方 1/3/4/6/7、己方 1/3/4/6/7；坐标厘米转米。
- 全局血量独立按己方 1/3/4/7、敌方 1/3/4/7 投影，不把无人机插入血量数组。
- 新增 GlobalUnitStatus 字段 15/16：total_cp_ally/total_cp_enemy，optional uint32。
- 指挥数据通过 GameData.command2027State 暴露。基地控制映射到固定红蓝阵营；
  前哨 R/B 表示初始地理身份，其状态归一化到红方视角。
- 字段 base_shield 在该指挥投影中解释为基地领地控制；不将其作为护盾数值展示。
- 特殊机制 3/4/5/6 对应 R/B 前哨、R/B 基地；保留有符号时间，正数己方推进、负数敌方推进。
  不推导百分比，不在本地倒计时。机制列表不再包含的条目立即清除。
- 未收到积分时显示 --，显式 0 显示 0；3.5 秒未收到状态标记过期。
  切换机器人或进入新回合清除指挥投影，避免带入旧视角数据。

界面读取字段表适配后的指挥投影。完整收发 Topic、上下行命令和表格优先规则见
[2027 自定义终端协议适配](protocol-convergence-plan.md)。模拟器阵容与规则仍需单独适配。
现有底图沿用仓库图片；没有根据本文档猜测新版区域位置或边界。

PDF 的 `RobotPosition` 字段 5 及雷达 protobuf 示例存在表格/示例不一致；
自定义终端保留 optional `robot_id`，雷达按重复 `uint32` 三元组实现。真实服务器包仍需现场核验。
